# Site de Redação

## Sobre o projeto
Este projeto consiste no desenvolvimento de um site voltado à prática de redação, com o objetivo de oferecer um ambiente simples e organizado para auxiliar estudantes no desenvolvimento da escrita.

## Funcionalidades
- Ambiente para prática de redação.
- Interface intuitiva e organizada.
- Estrutura de navegação simples.
- Layout adaptável a diferentes dispositivos.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Objetivo
Aplicar conhecimentos de desenvolvimento web, estruturação de páginas, estilização e lógica de programação por meio da criação de um projeto prático.
